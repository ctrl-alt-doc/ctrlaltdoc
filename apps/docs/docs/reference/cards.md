# Cards

Cards provide a visual way to group related links.

A cards group starts with `:::cards`. Each card uses the form `:::card[Title](URL)`.

## Basic cards

:::cards

:::card[Getting Started](/getting-started)
Start with the basics of ctrl alt doc.
:::

:::card[Installation](/getting-started/installation)
Install ctrl alt doc and create your first documentation project.
:::

:::

## External links

Cards can also link to external destinations.

:::cards

:::card[ctrl alt doc](https://ctrlaltdoc.cc)
Visit the ctrl alt doc website.
:::

:::

## Card content

Each card has a title, destination, and optional descriptive content.

Keep card descriptions short so the cards remain easy to scan.
