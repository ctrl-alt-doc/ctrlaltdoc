# Tabs

Use `tabs` when readers need to choose between related variants, such as package managers or operating systems.

:::tabs
== [terminal] pnpm

```bash
pnpm add ctrl-alt-doc
```

== npm

```bash
npm install ctrl-alt-doc
```

:::

Tabs support Markdown, code blocks, and callouts inside each panel.
